# My Temporary Home

## Portfolio Website

This repository contains a professional portfolio website built with HTML and CSS.

### How to Work with index.html in VS Code

#### Option 1: Using Live Server Extension (Recommended)
1. Install the "Live Server" extension in VS Code
2. Right-click on `index.html`
3. Select "Open with Live Server"
4. The page will open in your browser with auto-reload on save

#### Option 2: Using a Browser Directly
1. Right-click on `index.html` in VS Code Explorer
2. Select "Reveal in File Explorer" (Windows) or "Reveal in Finder" (Mac)
3. Double-click the file to open it in your default browser

#### Option 3: Using Python HTTP Server
```bash
# In the terminal (from the repository root)
python3 -m http.server 8080
# Then open http://localhost:8080/index.html in your browser
```

### Customizing the Portfolio

The portfolio includes three main sections that you can customize:

1. **Hero Section** - Update your name and introduction text
2. **Projects Section** - Replace placeholder projects with your actual work
3. **Contact Section** - Add your real email and social media links

- ✅ Responsive design (mobile, tablet, desktop)

### Editing the Content

Simply open `index.html` in VS Code and:
- Edit text content between HTML tags
- Update links in `href` attributes
- Modify colors in the `<style>` section
- Add your own projects by duplicating the `.project-card` sections
